Smart Cache Engine

3.2M ops/s (Zipf) 99.9% herd cutoff 79 tests · 0 deps 9 stars
  • Redis-inspired in-memory cache engine built from scratch in Node.js + Express — an O(1) Map + doubly-linked-list LRU, dual-layer TTL expiry (lazy on read plus a background sweep), and byte-level memory caps.
  • Redis-style Sorted Sets (ZADD / ZRANK / ZRANGE / ZINCRBY) with lazy-sort, plus a full REST API covering key-value, sorted sets, metrics, and get-or-load.

  • Metrics with p50/p95/p99 latency via reservoir sampling; validated by 79 tests on Node's built-in runner (zero extra deps) and a 10-scenario benchmark hitting 3.2M ops/s on a Zipf hot-key workload.
